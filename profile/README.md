# AGi — Amazing Grace infrastructure

AGi is the project behind **Grace** and **AuRoRA**.

Grace is an AI companion with a growing memory system. AuRoRA is an autonomous rover built to explore nature alongside her. Together, they bring local AI, robotics, and exploration into one project.

Built in Beautiful British Columbia, Canada.
